# رشد - نسخه ۲

نسخه دارای ذخیره دائمی اطلاعات است.

## امکانات
- افزودن افراد
- ذخیره اطلاعات در SQLite داخل خود گوشی
- باقی ماندن اطلاعات بعد از بستن و باز کردن برنامه
- حضور: +1
- غیبت موجه: +0.5
- غیبت: 0
- مثبت: +1
- منفی: -1
- محاسبه خودکار امتیاز
- حذف فرد و سوابق او

این پروژه برای ساخت APK در Android Studio آماده شده است.
